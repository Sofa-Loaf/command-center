# Command Center __VERSION__

Clipboard command palette for MSP/field techs. Copy, never execute remotely.

## Downloads (Windows 10/11 x64)

- NSIS installer (recommended): `Command Center_*_x64-setup.exe`
- MSI: `Command Center_*_x64_en-US.msi`
- Portable: `command-center.exe`
- Portable web zip: `Command-Center-__VERSION__-portable-win64.zip`

If Windows says “Windows protected your PC”, choose **More info → Run anyway**.

## Changes

- Command lists, tabs, favorites, search, and editors scroll inside their panels. Headers stay put.
- Display settings: scroll motion (system / smooth / instant) and list density (comfortable / compact), saved with the theme.
